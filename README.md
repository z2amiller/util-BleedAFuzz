# util-BleedAFuzz

A plug-in NPN transistor that biases like a lower-hFE part. In a
single-transistor fuzz with collector-feedback bias (a large resistor from
collector to base), the transistor's hFE mostly decides the DC collector
voltage, not the gain. So when everyone says a circuit "sounds best with a
125 hFE transistor" and all you have is 300s and 600s, what you actually need
is the collector voltage a 125 would give. This board gets you there with a
trimmer.

## How it works

Q1 is wired straight across the header. A fixed 1M plus a 1M trimmer from base
to emitter bleeds a settable share of the base drive, so the feedback resistor
has to supply more current and the collector rises exactly as it would with a
lower-hFE part. The bleed spans 1M to 2M. Effective hFE at a 50 µA stage:

| Bleed | BC847C (~600) | 2SC1815-GR (~300) |
| ----- | ------------- | ----------------- |
| 1M    | ~80           | ~70               |
| 2M    | ~140          | ~110              |

LEAK is an optional 2.2M collector-base resistor that mimics germanium
collector leakage (leave it off unless wanted).

Header order is E, B, C; plug a BC-series (C, B, E) socket in reversed.

## Example: Spirit in the Sky style fuzz (Overcast)

The Overcast is a Spirit in the Sky clone: one transistor, 6M collector-to-base
bias, 470R emitter, 100K collector load. With a 2SC1815-GR (hFE ~300) the
collector sits near 2.0 V; a 125 hFE part would put it near 3.3 V with the
gain control at minimum. Plug this board into the Q1 socket, put a meter on
the collector, and trim until it reads about 3.3 V. That is the 125 hFE sound.

For circuits where the transistor's input impedance matters too (a Fuzz Face
Q1 fed straight from the pickup), the companion
[util-DialAFuzz](https://github.com/z2amiller/util-DialAFuzz) is the better
tool.

## Gerbers

[GERBER-util-BleedAFuzz.zip](GERBER-util-BleedAFuzz.zip) is the JLCPCB-ready
gerber and drill set for rev 0.2 (tag util-BleedAFuzz-0.2-g2), generated by
kicad-jlcpcb-tools; no KiCad install needed to order the board. One SOT-23
BC847, two 0805 resistors (one optional), a 3-pin header and a through-hole 1M
trimmer on the back.

Utility board (`BOARD_STATUS=utility`), not an effects pedal. Fleet kit rules
live in `util-BleedAFuzz.kicad_dru`; see
[pedalfx/template/_fleet](https://github.com/z2amiller/pedalfx/tree/main/template/_fleet).
